Welcome to my corner of the internet. I've finally got round to setting up a blog, so here we are.

## Why am I doing this?

A few reasons, really:

1. **Documenting learnings** — I constantly learn new things but forget them just as quickly. Writing them down forces me to actually understand them.

2. **Helping others** — If I struggled with something, chances are someone else will too. Maybe this saves them a few hours of frustration.

3. **Building in public** — There's something to be said for putting your thoughts out there. It keeps you accountable.

## What to expect

This blog will cover:

- **Software engineering** — the meat and potatoes
- **DevOps and infrastructure** — Kubernetes, CI/CD, the works
- **Random observations** — sometimes I just need to rant about something

## A quick code example

Because what's a dev blog without some code? Here's a simple Go function:

```go
func greet(name string) string {
    if name == "" {
        return "Hello, stranger!"
    }
    return fmt.Sprintf("Hello, %s!", name)
}
```

And some TypeScript for good measure:

```typescript
const greet = (name?: string): string => {
  return name ? `Hello, ${name}!` : 'Hello, stranger!';
};
```
